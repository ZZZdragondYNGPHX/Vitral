# Vitral 产品规格 v1.2

Vitral 面向 Linux（Fcitx5，Wayland / X11）、Windows 10/11（TSF）和 Android 10 及以上版本。三端共享 Rust 输入核心以及深浅两套视觉令牌。Zero Bloat 将工具栏的范围限定在输入、编辑、剪贴板和传输。默认输入流程可离线使用，纯离线模式同时关闭局域网和外部网络操作。

## 拼音与词库

默认方案为小鹤双拼 `double_pinyin_flypy`，可切换到全拼 `rime_ice`。全拼允许多个音节切分参与整句解码，结合雾凇词库、万象语法和个人词频排序。词库导入支持搜狗 `.scel`、Rime `.dict.yaml`、TSV 和无注音的 `.txt`。导入的词条可用于拼音候选与连续手写重排，并随个人词库同步。

个人词频采用 Frecency。每次确认增加权重，此前的权重随时间指数衰减。桌面快捷键和移动端候选长按支持置顶及擦除。输入法按应用记忆中英文状态，识别混输中的英文和 URL，并提供成对标点、微空格及日期、时间宏 `rq`、`sj`。

## 手写与语音

| 输入方式 | 交互与识别 |
| --- | --- |
| 单字查音 | 保留当前笔迹直至用户选择或清空，支持慢写、补笔和连笔。候选显示字形、带声调全拼和小鹤编码，例如「耄 mào · mc」。 |
| 连续手写 | 支持原位叠写和横向连写，利用时间间隔、笔迹位置及字形判定边界。原位叠写的旧墨迹在 420 ms 内淡出。 |
| 离线语音 | 主机提供 16 kHz 单声道 PCM，由本机 SenseVoice-Small 模型转写。移动端长按空格 350 ms 开始语音输入，键位内显示声波。 |
| 可选 AI | 用户配置服务地址、模型及密钥后，可触发选区翻译、润色或录音摘要。连续手写的联网消歧只允许从有歧义字位的已有候选中选择。 |

连续手写为每个字位保留 Top-8 视觉候选。前两项置信度差低于 0.15 时，后文可修正该字。清晰字和用户手动选定的字保持锁定。第一层以词库、N-gram 和 1–6 字距离的共现关系进行束搜索，第二层用本机 INT8 双向模型重排，第三层为可选的联网消歧。前两层的设计延迟目标分别为 2 ms 以内和约 15 ms。

例如首字介于「曝」和「爆」时，先写「光」可显示「曝光」，后续输入「老登金币」可将首字修正为「爆」。整句在系统预编辑区内更新；修正的字位提示 600 ms，可手动改选后再提交。

## 剪贴板与文件传输

| 数据 | 保存位置 | 生命周期 |
| --- | --- | --- |
| 快捷粘贴 | 各设备内存 | 本机复制或接收新的远端复制事件时覆盖。点按后在本机清空。收起时已有展示的内容在下次打开时清除；收起期间的新复制在首次打开时展示。输入时让位给候选。 |
| 剪贴板历史 | `/Koofr/Vitral/clipboard/history_ring.jsonl.enc` | 保存最近 N 条及置顶项，满额时淘汰最旧的未置顶项。支持清空未置顶项，置顶内容可绑定候选缩写。历史按原文保存，包括复制的密码。 |
| 词库与配置 | `/Koofr/Vitral/lexicon/`、`profile/` | 长期保存个人词频快照、CRDT 增量、导入词库、常用语及设置，用于同步和恢复设备。 |
| 文件 | 局域网 LocalSend v2，跨网使用 `/Koofr/Vitral/relay/` | 接收方验证 SHA-256 后立即删除中转文件。未完成传输的孤立文件在 24 小时后清理。 |

一台设备消费快捷粘贴，其他设备仍可粘贴同一内容。冷启动恢复历史不会生成快捷粘贴，WebDAV 仅存放持久化数据。设备选择器可以横向滚动，综合局域网可达性、使用频次及远端在线状态排序。

## 跨平台界面

- 桌面候选窗定位在光标附近，每页横排五项。右下角状态胶囊初始显示徽标和中英文切换，工具图标可增删和确认。闲置 5 秒降到 35% 不透明度，贴边半隐，全屏时隐藏。
- 手机停靠键盘约占屏高 26%，依次排列图标工具栏、候选栏及按键。悬浮键盘可自由拖动和缩放，最小尺寸为 220 × 165 dp。空格滑动移动光标，退格键左滑连续删除。
- 小鹤双拼使用四排键，左上角标上滑数字或符号，右下角标韵母。全拼使用五排键，顶部为独立数字行，字母键右上角标上滑符号。数字面板为九宫格。
- 工具栏使用 1.75 px 线宽的矢量图标。桌面候选字号默认 16 px，可调范围 13–22 px。表面使用磨砂半透明材质、1 px 边缘和青蓝强调色，按键高光在键帽内显示。
- 桌面管理中心与移动端设置提供词库导入、剪贴板容量、云同步及设备恢复。剪贴板面板将置顶项与最近记录分组。翻译预览使用单行工具条，录音笔使用独立胶囊。

颜色、圆角、模糊半径、动效时长及触感参数以[设计令牌](../tokens/design-tokens.json)为准。宿主与核心的实现入口见[架构与模块](architecture.md)。
