# 全拼的长句解码

全拼（Quanpin）的音节长度可变。同一串按键可能对应不同切分，右侧上下文会影响前面的字词选择。

## 音节与词图

- 解码器以拼音字母偏移为顶点，将合法音节连成有向无环图。
- `xian` 可以是一个音节，也可以拆成 `xi/an`；显式输入的撇号限制可跨越的边界。
- `fangan` 可产生 `fang/an` 和 `fan/gan` 两条路径，对应「方案」和「反感」等候选。
- 字典将相邻音节组合成词边，基础词库和导入词条在同一张图上参与搜索。
- 小鹤双拼使用独立的按键到音节映射，之后可共用词库和个人排序。

## 路径评分

词频、上下文搭配、切分代价和个人使用频率共同决定完整路径得分。
将单字和词组的频次直接相加会偏向高频单字，词边评分因此区分单字与多字词。
语法查询以路径末尾的汉字作为上下文，由万象语法文件返回搭配权重。
不同长度的查询使用对应基线，避免通过拆出更多词边反复积累搭配分。
用户显式输入的音节分隔和推测得到的零声母切分也分别计分。

## 搜索与候选

有限宽度的 beam 为每个输入偏移保留多个候选前缀。
状态中保存最近的词和音节，以便后续词边重新评估先前的切分。
到达末尾后按整句得分收集候选，再合并相同的输出文本。
导入的热词可直接出现在词图上。个人置顶、选词和擦除由共享的排序层处理。

## 评价方法

按短、中、长输入分别比较首选整句命中率、正确文本在候选中的位置和错误切分。
延长拼音串时，应检查新增音节能否纠正先前的歧义。例如在「反感」之后追加与情绪相关的上下文。
带撇号和不带撇号的输入应分别检查，以区分用户给出的边界与统计推断。
语法文件、词库版本和个性化状态都会影响复现结果，记录输入样本时一并保留这些条件。

音节图与搜索见 [quanpin.rs](../../crates/vitral-core/src/eng/quanpin.rs)，语法索引见 [gram.rs](../../crates/vitral-core/src/eng/gram.rs)。相关开源实现包括 [librime](https://github.com/rime/librime) 和 [SunPinyin](https://github.com/sunpinyin/sunpinyin)。
