# 手写轨迹与上下文识别

Vitral 的 handwriting 引擎接收带时间戳的笔画坐标和抬笔标记。单字模式返回字形与读音，连续模式保留可回溯的预编辑文本。

## 轨迹分类与查音

DirectMap 把归一化轨迹栅格化到方向通道，将书写方向和字形位置一同交给 SE-ResNet 分类器。类别表定义 ONNX 输出下标对应的 Unicode 字符，须与模型配套使用。查音模式保留慢写和追加的笔画，候选显示带声调全拼及小鹤编码。[上游分类器与模型导出](https://github.com/mcyph/cnn_chinese_hw)

对于模型类别表以外的字，核心可尝试按左右或上下结构识别部件，再查 IDS 索引。例如「由」和「頁」按左右结构可组成「頔」。组合候选取决于笔迹切分、部件识别和字表覆盖范围。[CJKVI IDS 数据](https://github.com/cjkvi/cjkvi-ids)

## 切分与回溯

- 叠写使用抬笔间隔识别新字。横向连写还比较字框、水平距离以及拆分前后的视觉得分，以区分左右部件和两个独立字符。
- 每个字位保留 Top-8 混淆集。前两项概率差和部件置信度决定是否允许语境改写。清晰字形保留视觉首选，手动选择将相应笔画范围锁定。
- 第一层束搜索结合视觉分数、词典、万象语法、个人词频和跨词共现。第二层在歧义位置遮盖当前字，用 INT8 双向模型对已有备选重新计分。可选的第三层仅接受这些位置内的有效候选索引。
- 整句确认前使用宿主预编辑接口。回溯修正后更新对应字位并显示 600 ms 提示，用户仍可查看和修改该位置。

验证时分别覆盖慢写、倒插笔画、水平连写、清晰字形、歧义字形和手动锁定；同一段笔迹可追加不同后文，检查只有未锁定的位置随语境变化。视觉切分见 [lattice.rs](../../crates/vitral-core/src/hw/lattice.rs)，路径重排见 [rerank.rs](../../crates/vitral-core/src/hw/rerank.rs)。
